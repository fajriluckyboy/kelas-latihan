# Silabus Kelas: Pengantar Git & GitHub

## Deskripsi
Kelas ini mengajarkan dasar-dasar version control
menggunakan Git dan GitHub untuk pemula.

## Jadwal
| Minggu | Materi |
|--------|--------|
| 1 | Instalasi Git, konsep dasar |
| 2 | Branch dan Merge |
| 3 | Pull Request dan Code Review |
| 4 | GitHub Actions dasar |

## Cara Mengumpulkan Tugas
Setiap tugas dikumpulkan lewat Pull Request,
mengikuti template yang tersedia di repo ini.

## Penilaian
- Ketepatan waktu pengumpulan: 30%
- Kualitas kode: 40%
- Partisipasi review teman: 30%
